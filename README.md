# 🚀 Startup Sangam - Pitch Platform

![Startup Sangam Banner](https://via.placeholder.com/1200x400/2D3748/FFFFFF?text=Startup+Sangam+Pitch+Platform)

The official platform for **Udbhav**, MNNIT Allahabad's premier startup showcase event, connecting entrepreneurs with investors and mentors.

## ✨ Features

### 🎤 Pitch Management
- Startup application and profile creation
- Judging panel interface with scoring system
- Real-time results calculation

### 🏆 Event Management
- Automated schedule generation
- Live audience voting
- Digital certificate generation

### 📊 Admin Dashboard
- Comprehensive analytics dashboard
- Bulk email/SMS communication
- Exportable participant data

## 🛠 Tech Stack
**Frontend:** React.js, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Real-time:** Socket.IO  
**DevOps:** Azure Web Services

## 🚀 Getting Started
```bash
# Clone repository
git clone https://github.com/MNNIT-Startup-Sangam/Startup-Sangam.git

# Install dependencies
cd Startup-Sangam
npm install

# Configure environment
cp .env.example .env

# Start development server
npm run dev
